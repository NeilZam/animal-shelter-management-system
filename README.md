# Animal Shelter Management System

A Binary Search Tree (BST) application written in C that manages animal records and supports efficient searching, ranking, filtering, and deletion operations.

## Features

- Insert new animal records
- Search animals by name
- Delete records using BST deletion
- Rank animals using subtree metadata
- Filter animals by traits
- Dynamic memory allocation and cleanup

## Concepts Used

- Binary Search Trees
- Recursion
- Dynamic Memory Allocation
- Tree Traversal
- Algorithm Analysis

## Technologies

- C
- GCC
- Command Line

## What I Learned

This project strengthened my understanding of recursive data structures, memory management, and efficient searching algorithms.
